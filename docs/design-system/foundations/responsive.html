Overview

Styles are written for a phone first and add to themselves at each breakpoint. No screen is built for one size and patched for the rest.

What each component does

ComponentPhoneFrom 768 px
Listing grid1 column; 2 from 576 px3 columns; 4 from 1200 px
Search barStacked, button full width; one row from 576 pxOne row
SwitchTighter padding; scrolls inside itself if too wideFull padding
Browse headline36 to 48 px, buttons below60 px and buttons beside it from 992 px
Message boxBelow the listingBeside it, sticky
Post previewBelow the formBeside it, sticky
AdminTop bar and queue onlyRail, queue and detail panel
DialogBottom sheet under 640 pxCentred
ToastAcross the bottomBottom right corner

Touch

  • Every target is at least 44 × 44 px.
  • Nothing is revealed only on hover.
  • Inputs are 16 px so a phone does not zoom on focus.

Testing

  • Check 320, 360, 576, 768, 992, 1200 and 1440 px in both themes.
  • No screen may scroll sideways; long titles, long church names and four-digit counts are in browse/edge.
  • Check at 200% zoom.
