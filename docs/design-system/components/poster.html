Posted by

Who posted a listing and the church they belong to, each marked Verified when an admin has confirmed it.

Overview

People rent from people they can place. Under every listing: the member’s name, their church, and since when they have been a member. The member and the church are verified separately, so each carries its own mark.

Anatomy

  1. InitialsOn a pale tile; decorative.
  2. NameThe member’s name as they gave it.
  3. Verified marksOne for the member, one for the church.
  4. ChurchThe church’s name.
  5. Since“Member since 2023”.

Sizes

Posted by has one size.

States

Not interactive: it has no states.

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Posted by reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-border-default, --color-fg-default, --color-fg-muted. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A <section aria-label="Posted by">.

Keyboard

KeyAction
NoneNot focusable: it is read in document order.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

Each mark is the word “Verified” with an icon, followed for assistive technology by what it verifies: “Verified member”, “Verified church”.

Contrast

Name and church
Verified
Since

Motion

None.

Touch

Nothing to press.

Content

  • Never an email address, a phone number or a street address.
  • No mark at all when not verified. There is no “Unverified” label.
  • Names and church names are data and are rendered as text.
