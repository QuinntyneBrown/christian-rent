Layout primitives

The container, the stack and the cluster that every screen is laid out with.

WCAG 2.2 AAStatus: stable

Overview

Three small tools do most of the arranging. The container centres the page at 1152 px. The stack spaces things down a column. The cluster spaces things along a row and wraps. The grids for cards, for Listing and for Post are described in Layout.

Anatomy

  1. ItemAnything.
  2. GapFrom the spacing scale: 12 px in a cluster, 16 px in a stack.

States

Not interactive: they have no states.

Responsive behaviour

The container’s side margin is 16 px under 768 px and 24 px from there. Its width never exceeds 1152 px.

Theming

Layout primitives reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are inherited from its parent. To restyle it, change those tokens; never write a colour in the component.

Accessibility
