Foundation

Iconography

Line icons on a 24-unit grid, drawn in the colour of the text beside them.

WCAG 2.2 AA
  • Overview
  • The set
  • Sizes
  • Usage

Overview

Icons are inline SVG with a 2 px stroke, round caps and currentColor, in the style of Lucide, which the prototype used. They are bundled with the app; none is fetched.

Sizes

16 px beside small text, 20 px by default, 24 px in an empty state.

Usage

  • An icon beside a label is decoration: aria-hidden="true".
  • An icon alone on a button needs an aria-label that says what the button does.
  • An icon never carries a state by itself: Verified has its word, a wanted card says “Wanted”.
  • The mark is not an icon; see Logo.
