Skip link

The first thing the Tab key reaches: a link past the header to the content.

Overview

Every screen starts with it. It is off screen until it has focus.

Anatomy

  1. LinkRaised surface, --shadow-3, visible only on focus.

Variants

Skip to content
Shown, as when focused
HTML
<a class="skip-link" href="#variants" style="position: static;">Skip to content</a>

Sizes

Skip link has one size.

States

It has two states, hidden and focused, and the example above shows the focused one.

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Skip link reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-bg-surface-raised, --color-fg-default. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A link to #main, the screen’s one <main>.

Keyboard

KeyAction
Tab Reveals it; it is first in the order.
Enter Moves focus to the content.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

“Skip to content”.

Contrast

Text

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Not shown to touch; it serves the keyboard.

Content

  • Always “Skip to content”.
