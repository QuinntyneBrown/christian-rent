Line field

Post’s big field: a question, and an answer written large on a single line.

Overview

Use it on Post only, where filling in the fields is the whole screen and the answer deserves the display face. Everywhere else use the text field.

Anatomy

  1. LabelThe question, in muted semibold.
  2. Prefix (optional)“$” or “Up to $”.
  3. AnswerBricolage Grotesque, 24 px, semibold.
  4. Unit (optional)A quiet select: per hour, day, week or month.
  5. Line2 px in --color-border-strong; ink when the field has focus.

Responsive behaviour

The answer shrinks before it wraps: the input takes whatever the prefix and the unit leave. Price and When share a row only when the column is wide enough.

Theming

Line field reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-fg-muted, --color-border-strong, --color-fg-default, --color-focus-ring, --color-fg-subtle, --color-danger-solid. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A native <input> with a <label for>.

Keyboard

KeyAction
Tab Moves to the answer, then to the unit.
Enter Submits Post.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

The question is the label. The prefix is decorative and hidden from assistive technology; the unit select has its own hidden label, “Per”.

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • Labels are questions or plain nouns: “What is it?”, “What do you need?”, “Price”, “Your budget”, “When”, “Where”.
  • The example in the placeholder is a real listing: “Pressure washer and drill kit”.
  • “Where” is a city or neighbourhood, never a street address, and its help says so.
