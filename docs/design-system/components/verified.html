Verified mark

An icon and the word “Verified” beside a member or a church an admin has confirmed.

WCAG 2.2 AAStatus: stable

Overview

Verified means an admin has confirmed it. The mark appears beside a member’s name and, separately, beside a church’s name. When something is not verified there is no mark.

Anatomy

  1. IconA badge with a tick.
  2. Word“Verified”, in --color-success-fg.

Sizes

Verified mark has one size.

States

Not interactive: it has no states.

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Verified mark reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-success-fg. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

Inline text with a decorative icon.

Keyboard

KeyAction
NoneNot focusable: it is read in document order.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

The visible word is followed by a visually hidden one saying what is verified: “Verified member”, “Verified church”.

Contrast

On the page
On Admin’s canvas

Motion

None.

Touch

Nothing to press.

Content

  • Always the word “Verified”. Never “Trusted”, “Approved” or a tick alone.
  • Only an admin’s decision produces it; the frontend never infers it.
