Foundation

Layout

Four breakpoints, a 1152 px container, and one grid per screen.

WCAG 2.2 AA
  • Overview
  • Breakpoints
  • Columns, gutters and margins
  • Screen templates
  • Usage
  • Tokens

Overview

Every screen is designed from a 320 px phone to a wide desktop. Breakpoints are named for what changes at them, and each screen changes at the same ones.

Breakpoints

TokenWidthWhat changes
--layout-breakpoint-sm576 pxCards go to two columns; the search bar becomes one row.
--layout-breakpoint-md768 pxThree columns of cards. The message box moves beside the listing, the preview beside Post, the detail panel beside the queue.
--layout-breakpoint-lg992 pxWider gutters; the posting buttons move beside the headline; Admin’s rail shows its text.
--layout-breakpoint-xl1200 pxFour columns of cards.

Columns, gutters and margins

The page grid has 4 columns under 768 px, 8 from 768 px and 12 from 992 px. Resize the window to see it change.

Screen templates

ScreenPhoneTablet and desktop

PostSentence, fields, action, then the previewFields with the preview in a 320 px column beside them
AdminA top bar and the queue onlyA rail (72 or 240 px), the queue (448 px at most) and the detail panel

Usage

  • Content sits in .container, never edge to edge.
  • Nothing scrolls sideways at any width.
  • A side column is given as a maximum, so it gives way before the main column does.
