Kind filter

Narrows Browse to spaces or to things.

WCAG 2.2 AAStatus: stable

Overview

A listing is for a space or a thing. This filter sits beside the switch and applies together with it and with the search. It is in the prototype; no requirement covers it yet, so it is the first thing to drop if Browse gets crowded.

Anatomy

  1. Pressed optionInk fill; aria-pressed="true".
  2. Other optionsMuted text, no fill.

Variants

All, Spaces, Things
HTML
<div class="kind-filter" role="group" aria-label="Kind"><button class="kind-filter__option" type="button" aria-pressed="true">All</button><button class="kind-filter__option" type="button" aria-pressed="false">Spaces</button><button class="kind-filter__option" type="button" aria-pressed="false">Things</button></div>

Sizes

Kind filter has one size.

States

VariantDefaultHoverFocusPressed
Option

Responsive behaviour

It wraps under the switch when the two do not fit on one row.

Theming

Kind filter reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-fg-muted, --color-bg-subtle, --color-fg-default, --color-accent, --color-fg-on-accent. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A role="group" named “Kind” of toggle buttons with aria-pressed.

Keyboard

KeyAction
Tab Moves through the options.
Space Presses the option.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

Each button’s text is its name; the group’s name gives the context.

Contrast

Pressed
Not pressed

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • Plural nouns: “All”, “Spaces”, “Things”.
