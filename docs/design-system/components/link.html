Link

A link goes somewhere and changes nothing.

Overview

Use a link to move between screens: back to Browse, to a listing, to the site from Admin. If pressing it changes something, it is a button. Inline links are underlined, so colour is never the only cue.

Anatomy

  1. Icon (optional)Points the way the link goes.
  2. LabelSays where it goes.

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Link reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-fg-muted, --color-fg-default. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A native <a href>.

Keyboard

KeyAction
Enter Follows the link.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

The text says where the link goes without the words around it: “All listings”, not “Back”.

Contrast

Link on the page
Back link

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • Name the destination: “All listings”, “Back to site”, “Go to the next item”.
  • Never “click here”.
