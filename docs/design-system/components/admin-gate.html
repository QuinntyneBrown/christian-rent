Admin gate

Admin’s ink page around one card: the way into Admin, and the page for a signed-in person who is not an admin.

WCAG 2.2 AAStatus: stable

Overview

Admin is its own application, so what stands before the review queue looks like Admin, not like the site: the ink of the Admin navigation, the inverse logo, “Admin”, and one card. It holds the sign-in form or the forbidden page (L2-038).

Anatomy

  1. TopThe inverse logo, which stays in Admin, and the label “Admin”.
  2. CardThe page’s one task, on the surface colour.

Sizes

One size: the card is at most 30rem wide.

States

The gate has no states of its own; its card’s content has them.

Responsive behaviour

The page fills the viewport. Under 576 px the card fills the width with 16 px around it and 32 px inside; from 576 px it has more room inside.

Theming

--color-bg-inverse in both themes, as the Admin navigation; the card is --color-bg-surface with --shadow-3.
