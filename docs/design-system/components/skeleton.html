Skeleton

A grey shape where content is about to be.

WCAG 2.2 AAStatus: stable

Overview

While the first request is in flight, each screen shows skeletons in the shape of what will arrive, so nothing moves when it does. Nothing is shown for the first 300 ms.

Anatomy

  1. MediaThe photo’s 4:3 box.
  2. TitleOne and a half lines tall.
  3. TextLines of different lengths.

Variants

Text, title, circle and rectangle
HTML
<div style="flex: 1 1 14rem;" aria-hidden="true"><span class="skeleton skeleton--title"></span><span class="skeleton skeleton--text"></span><span class="skeleton skeleton--text"></span></div><span class="skeleton skeleton--circle" style="width: 3rem; height: 3rem;" aria-hidden="true"></span><span class="skeleton skeleton--rect" style="width: 8rem; height: 6rem;" aria-hidden="true"></span>
A listing card
HTML
<div style="width: 16rem;" aria-hidden="true"><div class="listing-card"><div class="listing-card__media skeleton"></div><div class="listing-card__body"><span class="skeleton skeleton--title" style="width: 75%;"></span><span class="skeleton skeleton--text" style="width: 55%;"></span><span class="skeleton skeleton--text" style="width: 40%;"></span></div></div></div>

Sizes

Skeleton has one size.

States

Not interactive: it has no states.

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Skeleton reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-bg-subtle, --color-bg-subtle-hover. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

Hidden from assistive technology (aria-hidden="true"). The container has aria-busy="true" and a visually hidden status says “Loading listings”.

Keyboard

KeyAction
NoneNot focusable: it is read in document order.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

None of its own.

Contrast

Shape on the page

Motion

A slow shimmer. Reduced motion stops it and leaves the plain shape.

Touch

Nothing to press.

Content

  • The hidden status names what is loading: “Loading listings”, “Loading listing”, “Loading the queue…”.
