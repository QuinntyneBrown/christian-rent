Switch (Everything, For rent, Wanted)

Browse’s switch between everything, what is for rent and what is wanted.

Overview

Three views of the same list. The choice is kept in the address with the search term, so a reload or a shared link restores it. Because each option is an address, each is a link, and the chosen one is the current one.

Anatomy

  1. Track--color-bg-subtle, a pill.
  2. Current optionA raised white pill; aria-current="true".
  3. CountHow many listings that view holds, in regular weight.
  4. Other optionMuted until hovered.

Responsive behaviour

Under 576 px the options tighten their padding. If the counts are too wide (four digits on a 320 px phone) the track scrolls sideways inside itself; the page never does.

Theming

Switch (Everything, For rent, Wanted) reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-bg-subtle, --color-fg-muted, --color-fg-default, --color-bg-surface. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A <nav aria-label="Show"> of links; the chosen one has aria-current="true".

Keyboard

KeyAction
Tab Moves through the three options.
Enter Shows that view.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

The option’s text and its count are read together: “For rent 4”. The count has no separate label.

Motion

The white pill moves over --duration-base; reduced motion makes it instant.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • The words are fixed: “Everything”, “For rent”, “Wanted”.
  • Counts use thousands separators: “1,204”.
