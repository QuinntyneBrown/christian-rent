Admin navigation

The ink rail in Admin: the logo, who the admin is, the review queue with its count, and the way back to the site.

WCAG 2.2 AAStatus: stable

Overview

Admin has one screen, the review queue, so the navigation has one item. It exists to say where you are, how much is waiting and how to leave. Admin’s code, this component included, is loaded only for an admin.

Anatomy

  1. LogoWhite on ink; links to the site.
  2. Label“Admin” and the admin’s name.
  3. ReviewThe current page.
  4. CountHow many items wait, on orange.
  5. Back to siteLeaves Admin.

Sizes

Admin navigation has one size.

States

Its link takes the hover, focus and current states of any link; the count has none.

Responsive behaviour

Under 768 px it is a bar across the top: logo, queue icon, exit icon. From 768 px it is a 72 px rail of icons. From 992 px it is a 240 px rail with text and the count.

Theming

The rail is --color-bg-inverse in both themes: ink on light, a raised navy on dark.

Accessibility

Role and pattern

A <nav aria-label="Admin">; the queue’s link has aria-current="page".

Keyboard

KeyAction
Tab Logo, Review, Back to site.

Focus

On ink the focus ring is drawn in --color-fg-inverse, so it stays 3:1 against the rail.

Labelling

When the rail collapses to icons, each link keeps its name through aria-label. The count’s label says what it counts: “4 waiting”.

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • “Review”, “Back to site”. The label is “Admin · ” and the admin’s name.
