Photo picker

Adds up to six photos to a listing for rent, and shows which one goes on the card.

WCAG 2.2 AAStatus: stable

Overview

It appears on Post only when the sentence says “have”; a wanted listing has no photo. Photos are optional: a listing with none shows a stand-in on its card.

Anatomy

  1. Thumbnail4:3, --radius-md.
  2. “On the card” tagMarks the first photo, the one Browse shows.
  3. RemoveA 44 px target in the corner.
  4. AddA dashed tile that opens the file chooser.

Responsive behaviour

Tiles are a fixed 128 × 96 px and wrap onto as many rows as they need.

Theming

Photo picker reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-bg-surface-sunken, --color-bg-backdrop, --color-border-strong, --color-fg-muted, --color-fg-default. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A list of images, each with a remove <button>; Add is a button that opens a native file input.

Keyboard

KeyAction
Tab Moves through Remove buttons, then Add.
Enter Removes the photo, or opens the file chooser.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

The group is named “Photos” with the count, “1 of 6”. Each Remove names its photo. An upload in progress is a role="status". A refused file is announced with role="alert".

Contrast

Add label
Add edge

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • Help: “Up to 6. JPEG, PNG or WebP, 10 MB or less each. The first one is shown on the card.”
  • A refusal names the file and every limit: “‘garage-raw.tiff’ wasn’t added. A photo must be a JPEG, PNG or WebP of 10 MB or less, at least 400 × 300 px and at most 8,000 px on a side.”
  • Full: “That’s all 6 photos. Remove one to add another.”
