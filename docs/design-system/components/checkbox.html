Checkbox

One thing a person agrees to: the declaration that they are a Christian.

WCAG 2.2 AAStatus: stable

Overview

Use a checkbox for a single yes that the person must give themselves. It is never ticked for them.

Anatomy

  1. Box20 px inside a 44 px row; ink when ticked.
  2. LabelThe statement itself, in the first person.
  3. Description (optional)Why it is asked.

Variants

With a description
HTML
<label class="choice"><input type="checkbox" checked><span class="choice__text">I am a Christian<small>christian.rent is for Christians.</small></span></label>

Sizes

Checkbox has one size.

States

VariantUntickedTickedFocusInvalidDisabled
Checkbox

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Checkbox reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-border-strong, --color-bg-surface, --color-accent, --color-fg-on-accent, --color-bg-subtle, --color-border-default and others listed under Tokens. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A native <input type="checkbox"> inside its <label>.

Keyboard

KeyAction
Space Ticks or unticks.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

The label is the statement. An error is tied with aria-describedby.

Contrast

Tick on ink
Box edge

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

The whole row, label included, is the target and is at least 44 px tall.

Content

  • Write the statement the person is making: “I am a Christian”.
  • If it is left unticked: “Tick the box to declare that you are a Christian.”
