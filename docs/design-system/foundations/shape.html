Shape

Overview

The product is friendly, so corners are large. Buttons, tags and the switch are pills. Radius grows with the size of the thing.

Usage

  • Photos and cards use --radius-lg; the large photo on Listing, the search bar, the message box and dialogs use --radius-xl.
  • Anything pressed that holds a label is a pill.
  • Do not add a radius between the steps.
