Select

One choice from a list that is too long to lay out: a member’s church, the period a price is per.

WCAG 2.2 AAStatus: stable

Overview

Use the native select. Use a radio group for four choices or fewer, and the word toggle for the two pairs in Post’s sentence.

Anatomy

  1. LabelAbove the box.
  2. Chosen optionThe first option is the prompt “Choose a church” until one is chosen.
  3. ArrowDrawn in the text colour.

Variants

Boxed, and the quiet unit select inside a line field
HTML
<div style="flex: 1 1 16rem;"><select class="select" aria-label="Your church"><option>Grace Community Church, Langley</option><option>Cornerstone Church, Langley</option><option>My church isn’t listed</option></select></div><select class="line-field__unit" aria-label="Per"><option>per hour</option><option selected>per day</option><option>per week</option><option>per month</option></select>

Sizes

Select has one size.

States

VariantDefaultFocusInvalidDisabled
Select

Responsive behaviour

It takes the width of its container and wraps its text; it has no breakpoint of its own.

Theming

Select reads only semantic tokens, so it follows the theme with no rule of its own. The colour tokens it reads are --color-fg-default, --color-bg-surface, --color-border-strong, --color-fg-muted, --color-focus-ring, --color-danger-solid and others listed under Tokens. To restyle it, change those tokens; never write a colour in the component.

Accessibility

Role and pattern

A native <select>.

Keyboard

KeyAction
Space Opens the list.
↑ ↓ Move through the options.
Enter Chooses.

Focus

The shared focus ring: a 2 px outline in --color-focus-ring, offset 2 px, never removed.

Labelling

A visible label, or a visually hidden one for the unit beside a price (“Per”).

Contrast

Text
Edge

Motion

Colour and position changes take --duration-fast or --duration-base with --ease-standard. With reduced motion the tokens drop to 0.01 ms, so nothing moves.

Touch

Every interactive part is at least 44 × 44 px (--target-min). Nothing depends on hover.

Content

  • Options are in sentence case, churches with their city.
  • The last church option is always “My church isn’t listed”, which reveals a name and a city.
  • Periods are “per hour”, “per day”, “per week”, “per month” and nothing else.
